# Contributing to Android Survey App

Thank you for contributing to the Android Survey platform!

## Android Development Standards
- Maintain Material Design 3 guidelines for consistent touch targets, typography, and card elevations.
- Handle device rotation and configuration changes safely without re-triggering network queries.
- Ensure Firebase Realtime Database writes validate payload schema.

## Pull Request Guidelines
- Verify build with `./gradlew assembleDebug` or Android Studio build check.
- Include screenshot or screen recording for any visual changes.
