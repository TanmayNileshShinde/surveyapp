# 📋 Survey App

> A native Android application designed to gather and analyze insights across gaming, academics, and tech.

## 📖 About The Project

This project is a comprehensive mobile survey platform built natively for Android. It was designed to handle a wide variety of data collection needs, providing a seamless, mobile-optimized experience for users taking surveys on their phones. From gathering feedback on college experiences to analyzing gamer setups and polling opinions on F1 Racing, the app dynamically handles different questionnaire structures and securely processes the incoming data.

## ✨ Key Features

* **Diverse Survey Categories:** Supports distinct survey types out of the box, including:
  * 🎓 **Academic & Campus:** Student surveys, College feedback.
  * 🎮 **Gaming:** Valorant, Minecraft Hypixel, Gamer Setup.
  * 🏎️ **Sports & Interests:** F1 Racing.
  * 💻 **Tech & Feedback:** Developer insights, Smartphone Usage, App Feedback.
* 📊 **Real-Time Data Aggregation:** Instantly captures and processes survey responses for quick analysis.
* 📱 **Native Android UI:** Built with Material Design principles for a smooth, intuitive mobile experience.
* 🔒 **Secure Data Management:** Ensures all incoming survey submissions are routed and stored safely using Firebase.

## 🛠️ Tech Stack

* **UI / Design:** XML, Android Material Design
* **Logic:** Java / Android SDK
* **Database/Tools:** Firebase, Gradle, Git
